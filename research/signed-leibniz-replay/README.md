# Faster complete dyadic-capacity replay

This contribution was produced by Nick Petalas. Apache-2.0.

Claim type: scoped implementation-preservation proof and local performance
result. The complete [Ali Romman PR5615](https://github.com/CrocSwap/integer-mult-bounds/pull/5615)
capacity replay takes **9.83% less median wall time** with a bounded exact
Leibniz evaluator. Five alternating fresh-process pairs measured
0.131713167 s to 0.118766042 s. Reference range is 0.130969667 to
0.142122583 s; scheduled range is 0.118456500 to 0.121716458 s.
All ten complete scientific outputs are identical, with zero errors.

The change evaluates sizes one and two directly and initializes the 154 signed
permutations through size five once. It caches no matrix entries, determinants,
certificate decisions or scientific outputs. The original capacity algorithm,
independent minor oracle, source checks and complete caller remain unchanged.
This is an isolated opt-in adapter; no shared default command is changed.

The first signed-schedule-only experiment was inconclusive after adapter
overhead. Profiling then identified the 18,778 size-one and size-two requests.
Direct evaluation supplied the first clear improvement; optimization stopped.
The final generated [measurement](MEASUREMENT.json) binds the executing source
and all five declared inputs. It includes process startup, imports, source
authentication and the complete caller, rather than only the determinant loop.
Its final five-pair rerun records the numbers above. Timing is descriptive and
does not gate CI or promise a speedup on another host.

## Evidence

[PROOF.md](PROOF.md) shows exact equality of the evaluator for square integer
and rational matrices of sizes zero through five, and why replacing that one
function preserves each original certificate predicate.

The standalone verifier checks, in each normal or optimized run:

- All 19,654 requested determinants against the original evaluator, with an
  ordered matrix/value transcript. The dimension counts are
  `[0, 10331, 8447, 705, 138, 33]`.
- The complete source caller in reference, scheduled and comparison modes,
  retaining its 2,401 integer matrices, 75 rectangular dyadic matrices, causal
  and joint witnesses, and five original rejection controls.
- 154 signed schedules with a separate cycle-parity check; 1,248 explicit
  conformance values, including rational, large-integer and mutable inputs.
- Six domain or evaluator corruption controls, plus five actual corrupted-input
  executions. Every declared input is corrupted separately in a disposable
  Git-free export and rejected before scientific execution. The unchanged
  export also completes with an empty PATH.
- All ten recorded benchmark outputs, the source hashes, sample order and
  summary arithmetic. Receipts are generated by the scripts, never handwritten.

The complete determinant transcript has SHA256
`868f3a5d2c37364d7a93986027182bc08b620f98d2ddb6daf7ec945875edea39`.
No predecessor mathematical theorem is re-audited as this contribution.

## Reproduce

From the repository root, with CPython 3.12 and the standard library:

```sh
/Users/nick/git/integer-mult-bounds/.venv/bin/python3.12 -I -W error -B research/signed-leibniz-replay/verify.py
/Users/nick/git/integer-mult-bounds/.venv/bin/python3.12 -I -O -W error -B research/signed-leibniz-replay/verify.py
/Users/nick/git/integer-mult-bounds/.venv/bin/python3.12 -B scripts/research_package.py --package research/signed-leibniz-replay
/Users/nick/git/integer-mult-bounds/.venv/bin/python3.12 -B scripts/check_research_commit.py --package research/signed-leibniz-replay --check-source-history
```

Another CPython 3.12 path may replace the local path. Direct checks print
`PASS_SIGNED_LEIBNIZ_REPLAY` in JSON. The registered launcher prints
`PASS_REGISTERED_RESEARCH_PACKAGE`. Both registered checks have 120-second
limits and take less than five seconds locally. They write no package files.
Set TMPDIR to a chosen scratch directory to place disposable exports there.

To measure a different host, supply a fresh path outside the checkout:

```sh
/Users/nick/git/integer-mult-bounds/.venv/bin/python3.12 -W error -B research/signed-leibniz-replay/benchmark.py --output /absolute/scratch/measurement.json
```

The reference arm runs the original script directly. The scheduled arm runs
`adapter.py --engine scheduled`. Each process has a private empty bytecode
namespace; both use warning-strict execution and disabled bytecode writes.
Source imports in the adapter explicitly bypass cached bytecode.
The benchmark never overwrites an existing output.
