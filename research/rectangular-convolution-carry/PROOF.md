# The sharp unsigned convolution carry envelope

This contribution was produced by Nick Petalas. Apache-2.0.

## Statement

Let B>=2 and a,b>=1 be integers. Write s=min(a,b), l=max(a,b), L=a+b.
Let x_0,...,x_(a-1) and y_0,...,y_(b-1) be integers in [0,B-1]. Leading
zeros are allowed. Define

```text
c_i = sum_(j+k=i) x_j y_k,      0 <= i <= L-2,
c_(L-1) = 0,
K_0 = 0,
K_(i+1) = floor((c_i+K_i)/B),   0 <= i <= L-1.
```

For every such input, K_k <= U_k, where

```text
U_0 = 0,
U_k = min(k,s)(B-1)-1,    1 <= k <= l,
U_k = (L-k)(B-1),         l < k <= L.
```

One pair simultaneously attains equality at every k: all x_j and y_k
equal B-1. Thus U is the exact positionwise maximum, and

```text
max_(inputs,k) K_k = s(B-1)-1.
```

The maximum includes K_0 and K_L. In the boundary case B=2,s=1 it is
zero, so no negative or omitted boundary exception is needed.

## Monotonicity reduces sharpness to one pair

Let n_i be the number of pairs (j,k) with 0<=j<a, 0<=k<b and j+k=i.
Each summand is nonnegative and at most (B-1)^2. Therefore

```text
c_i <= C_i := n_i(B-1)^2.
```

Every C_i is attained simultaneously by the all-maximal digit pair.
The function (c,K) -> floor((c+K)/B) is nondecreasing in both arguments.
Induction from K_0=0 shows that every carry sequence is bounded by the
one generated by C. This also proves simultaneous attainment once that
single recurrence is evaluated. The same explicit input realizes every
coefficient maximum.

## Evaluate the maximal-digit recurrence

Exchange the operands if necessary, so a=s and b=l. The coefficient
multiplicities are

```text
n_i = i+1,       0 <= i < s,
n_i = s,         s <= i < l,
n_i = L-1-i,     l <= i <= L-1.
```

An empty interval contributes no case. The final multiplicity is
n_(L-1)=0. Put t=B-1. The first update gives

```text
t^2 = B(B-2)+1,
U_1 = B-2 = t-1.
```

For 1<=i<s, assume U_i=it-1. The next numerator is

```text
(i+1)t^2 + it - 1 = B((i+1)t-1).
```

Its quotient is U_(i+1)=(i+1)t-1, with no remainder. For the plateau
s<=i<l, using U_i=st-1 gives

```text
st^2 + st - 1 = B(st-1)+(B-1).
```

The quotient stays st-1. At i=l the first falling multiplicity is s-1,
and U_l=st-1, including when s=l. Thus

```text
(s-1)t^2 + st - 1 = B(s-1)t+(B-2),
U_(l+1) = (s-1)t.
```

The remainder B-2 lies in [0,B-1]. For l<i<L, put n=L-1-i and use
U_i=(n+1)t. Then

```text
nt^2 + (n+1)t = Bnt+(B-1),
U_(i+1) = nt.
```

These equations prove the displayed envelope, including U_L=0. They
also cover s=1: the first falling step directly produces U_L=0.
The rising part never exceeds st-1. The largest falling value is
(s-1)t, and st-1-(s-1)t=B-2>=0. The plateau therefore attains the
claimed uniform maximum.

## Exact binary capacity consequence

A conventional unsigned binary field holding integers from zero through
M=s(B-1)-1 requires exactly bit_length(M)=ceil(log2(s(B-1))) bits.
For M=0 this is zero value bits, without claiming zero physical overhead.
The older sufficient square-input cap q(B-1) requires
ceil(log2(q(B-1)+1)) bits under the same numeric representation.
The sharper cap saves one value bit precisely when q(B-1) is a power
of two. For binary radix and q=2^h this saves one bit, including h=0.
This is a numeric range comparison. Other fields, physical layout and
implementation costs are not counted.

## Scope and predecessors

Jose Manuel / jmbarrancoml's PR3787 supplies the fixed-tape FFT word
multiplier and its radix-convolution carry contract. James Reed / jwr404's
PR3808 supplies the sufficient q(B-1) cap and a finite recovery check on
that square-input geometry. Those results are cited, not audited or
replayed. The new result is the sharp envelope for rectangular unsigned
digit convolution, with simultaneous attainment and the resulting exact
numeric capacity. Radix multiplication, monotonicity and induction are
classical methods; no literature-priority claim is made.

The universal quantifiers follow from this proof. The standalone checker
corroborates the formula on independent finite rectangular products and
maximal-digit recurrences. It does not execute a predecessor verifier,
FFT backend, selected supplier or encoded-tape implementation. Signed
digits, nonzero initial carry, arbitrary coefficient streams and rounded
coefficient acquisition need their own contracts. All five selected
framework assumptions remain. There is no new kappa or full multiplication
theorem, and independent human and formal proof-kernel review are unclaimed.
